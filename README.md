# AM32 Port for К1921ВГ5Т

<p align="left">
  <a href="/LICENSE"><img src="https://img.shields.io/badge/author%20changes-GPL--3.0-brightgreen" alt="Author changes license: GPL-3.0"></a>
</p>

Проект посвящён управлению бесколлекторным двигателем на микроконтроллере
К1921ВГ5Т разработки НИИЭТ. Он продолжает работу над
[портом AM32 для К1946ВК035](https://github.com/RRegulo/K19XXVK035_AM32).
В основе — код AM32 с аппаратной частью для ВГ5Т. Дополнительные протоколы
и режимы убраны, оставлен классический PWM-вход. Это неофициальный порт,
адаптированный для ВГ5Т в 2026 году.

## 🔍 Отличия от оригинального AM32

Это не полная сборка AM32. Прошивка предназначена для простой платы ESC и
содержит только функции, необходимые для управления бесколлекторным мотором:

- классический PWM-вход;
- преобразование газа и ограничение его изменения из AM32;
- arm после секунды нулевого газа и остановка при потере сигнала;
- шестишаговая коммутация;
- startup- и arming-мелодии через фазы мотора;
- sensorless closed loop по переходам через ноль обратной ЭДС;
- три пары PWM с dead-time;
- измерение напряжения батареи через ADC.

Набор функций намеренно ограничен: не вся периферия и не все режимы ВГ5Т
проверены на реальной плате. Проект будет дополняться по мере тестирования
железа и подтверждения работы отдельных функций.

Проект открытый и находится в разработке: в прошивке, настройках и документации
возможны ошибки и неточности. Если вы нашли проблему или хотите предложить
улучшение, создайте issue или отправьте pull request. Результаты испытаний
на других платах и моторах тоже будут полезны.

Запуск и коммутация работают по алгоритму AM32. На малых оборотах прошивка
опрашивает компаратор свободной фазы, после раскрутки переходит на прерывания.
Сохранены фильтрация BEMF и опережение коммутации. Ограничение мощности на
низких оборотах отключено; защита от заклинивания в заводских настройках выключена.

В проект не входят DShot, двунаправленный DShot, DMA, телеметрия, демагнетизация,
измерение тока и температуры, синусоидальный запуск, режимы автомобиля,
регулятор оборотов и другие функции
полной версии AM32.

## ⚙️ Раскладка выводов

| Вывод | Назначение |
| --- | --- |
| PA8 / PA9 | PWM0_A / PWM0_B, фаза C |
| PA10 / PA11 | PWM1_A / PWM1_B, фаза B |
| PA12 / PA13 | PWM2_A / PWM2_B, фаза A |
| PA14 | Вход PWM-сигнала, TMR0_IO |
| PB0 | Напряжение батареи, ADC channel 0 |
| PB4 / PB5 / PB6 | Выходы компараторов обратной ЭДС фаз A / B / C |

## 📥 Установка и сборка

Для Windows и Linux можно установить инструменты через [Node.js](https://nodejs.org/)
(22 LTS или новее):

```sh
npm install
npm run configure
npm run build
npm run configure:debug
npm run build:debug
```

`npm install` устанавливает xpm, который загружает RISC-V GCC/GDB, CMake и Ninja
для текущей системы. Результат сборки находится в каталоге `build-xpack`.
Для отладки отдельно установите OpenOCD НИИЭТ, как описано ниже: обычная сборка
OpenOCD из xPack не содержит драйвера Flash К1921ВГ5Т.

Команды `configure:debug` и `build:debug` используют отдельный каталог `build-debug`.

Понадобятся CMake, Ninja и `riscv-none-elf-gcc` с multilib
`rv32imafc_zicsr_zifencei` / `ilp32f`.

- [RISC-V GCC xPack 14.2.0-3](https://github.com/xpack-dev-tools/riscv-none-elf-gcc-xpack/releases/tag/v14.2.0-3) — компилятор и `riscv-none-elf-gdb`.
- [OpenOCD от НИИЭТ](https://gitflic.ru/project/niiet/openocd/release/4a4e7431-0990-455c-9a8b-487bc98f72f8/87bb57bf-b4d3-4ce4-8f0b-85bb685facbb/download) — сборка с поддержкой К1921ВГ5Т.
- [K1921VG5T SDK](https://gitflic.ru/project/niiet/k1921vg5t_sdk) — исходный SDK НИИЭТ; его исходники уже включены в каталог `platform` этого репозитория. Актуальные скрипты OpenOCD находятся в `tools/openocd/scripts`.

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=cmake/riscv-none-elf.cmake \
  -DCMAKE_BUILD_TYPE=Release \
  -DUSE_BOOTLOADER=OFF
cmake --build build
```

`USE_BOOTLOADER=OFF` используется по умолчанию: приложение начинается с `0x0000`,
тактирование настраивает сама прошивка. Этот режим используется для текущих испытаний.

Дефолтные параметры находятся в `Src/settings.c` и размещены в образе по
адресу `0xF000`. Раскладка блока параметров AM32 сохранена, но протокола
настройки в этой версии нет. Входной диапазон по умолчанию — примерно 1006–2006 мкс,
направление вращения задаётся параметром `dir_reversed`.

Для сборки под загрузчик укажите `-DUSE_BOOTLOADER=ON`. Тогда приложение
начинается с `0x1000`; исходный код загрузчика в репозиторий не входит.

## 🔌 Прошивка и отладка

В `.vscode/launch.json` есть профили J-Link. Установите расширения
[CMake Tools](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cmake-tools)
и [Cortex-Debug](https://marketplace.visualstudio.com/items?itemName=marus25.cortex-debug).
Для Windows нужен OpenOCD НИИЭТ с поддержкой VG5T.

1. Скачайте `sc-dt_Patch_Niiet_Win32.zip` из [релизов OpenOCD НИИЭТ](https://gitflic.ru/project/niiet/openocd/release) и распакуйте в Syntacore DT.
2. Задайте `OPENOCD_NIIET` как путь к каталогу `tools` из установки, например:

   ```powershell
   setx OPENOCD_NIIET "C:\sc-dt\tools"
   ```

   Перезапустите VS Code. Профили J-Link ищут OpenOCD и скрипты в `bin` и `share/openocd/scripts` внутри этого каталога.
3. В Zadig выберите **BULK interface (Interface 2)** J-Link и установите **WinUSB**. Interface 0 (USB-UART) не меняйте; после установки переподключите J-Link.

ВГ5Т сообщает CHIPID `0x04e4c300`. Linux-сборка OpenOCD НИИЭТ ожидает `0x04e4c400`; для неё Dockerfile применяет проверяемую поправку. Это исправление только для указанной Linux-сборки. Windows OpenOCD используйте из Win32-архива без переноса этого патча.

Для отладки по JTAG используется `openocd/k1921vg5t-workarea.cfg`: он задаёт рабочую область OpenOCD в RAM отдельно от данных и стека приложения.

## Dev Container

В репозитории есть `.devcontainer` для VS Code и GitHub Codespaces (Linux x64).
После команды **Dev Containers: Reopen in Container** контейнер сам скачает
RISC-V GCC/GDB, OpenOCD НИИЭТ, скрипты SDK, CMake, Ninja и Node.js 22. CMake Tools настроит
сборку с `USE_BOOTLOADER=OFF`. Если J-Link доступен контейнеру по USB, выберите
`Debug K1921VG5T (Dev Container)`; профиль Windows использует путь из переменной
`OPENOCD_NIIET`.

Контейнер запускается с `--privileged`, чтобы OpenOCD имел доступ к J-Link по
USB. В образ также включена поправка CHIPID для текущих кристаллов ВГ5Т:
поставляемый НИИЭТ бинарник ожидает `0x4e4c400`, тогда как кристалл сообщает
`0x4e4c300`.

В Codespaces можно собрать прошивку; для отладки нужен доступ к J-Link.
На Windows USB-программатор нужно отдельно передать в среду Docker/WSL:
одного `--privileged` для этого недостаточно.

## 🐛 Известные ограничения

Перед первым включением необходимо сверить порядок фаз и полярность входов
компараторов с конкретной силовой платой. Неверный порядок фаз или фронт
компаратора не позволят двигателю перейти из запуска в closed loop.
